Intentional external dependency
-------------------------------
The live support conversation calls POST /chat as specified by the PRD. That
backend endpoint belongs to Task 6 and is not implemented on the current main
branch. Task 8 does not provide a competing fake endpoint in live mode. Once
Task 6 lands, setting VITE_USE_MOCKS=false activates the real chat request
without another Task 8 route change.

Live Firebase/Firestore integration still requires project credentials and a
running backend. Those environment-specific checks cannot be performed from the
repository alone.
